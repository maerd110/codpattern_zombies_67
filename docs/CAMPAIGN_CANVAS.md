# 战役逻辑画布（0.2.35b）

## 先部署地图

使用原部署工具注册地图、玩家初始出生点、初始怪物刷新点和需要的交互设备。工具中的「NPC 剧情」与「战役逻辑画布」均进入统一工作区。

工作区自动显示已经部署的地图，不会凭空创建地图几何。地图分区的半透明背景随节点范围自动变化。存在部署问题的地图可在右侧查看具体原因，完成必需校验后才能加入新战役章节。

「＋ 新建」→「连续战役」选择首关。选择其他地图分区，加入当前战役；章节属性可以调整中文名称、章节顺序、通关收藏奖励。同一地图可以作为多个章节使用；它们共用该地图的物理 NPC 配置，人物状态和流程前置条件随当前章节与故事历史判断。

## 编辑 NPC 和复用人物

选择地图分区中的块，点击「NPC / 节点」或双击流程节点，进入已有的详细 NPC 编辑器。原有动作、分段对话、等待、条件、全队投票和本地执行连线继续使用；退出后回到当前战役工作副本。

先在真实地图选定位置新增 NPC，再选择它的「已在地图放置」卡片，保存为跨关人物模板。模板复用人物身份、外观、皮肤、称呼和默认台词，剥离原地图坐标。本关规则单独编辑，不会把旧地图的坐标动作一起搬进新关。

后续地图使用「引用已保存的人物」，会出现「尚未选择放置位置」的引用块。此时没有新增地图 NPC，也没有生成实体。进入该关卡所在维度，选择当前位置或准星方块上方实际放置，再保存工作区。服务端仍会检查地图边界、外观和引用。

更新人物模板不会自动覆盖后续地图中已经放置的 NPC 配置。人物的生死、隐藏等剧情状态通过人物资源的效果连线和本章绑定控制。

## 剧情资源

「＋ 新建」提供剧情道具、重要状态、战役任务、战役事件和账号收藏。资源库中的同一条目可被多个章节引用，中文名称与内部身份分开；界面自动生成内部身份，不必抄写物品数据。

- 剧情道具：名称、说明、展示外观。主手持部署工具，把展示用物品放入副手后读取外观。数量写入玩家自己的存档剧情仓库，不作为跨关战斗装备带入。
- 重要状态：通过效果写入值，作为后续节点的前置条件。
- 战役任务：说明作为当前任务提示；效果可将其设为进行中、完成或失败。
- 战役事件：选择所属章节、最早波次，按名称选择物品、状态、人物、任务或收藏组成效果列表。
- 账号收藏：按原有结算规则发放；收藏属于账号，不混入故事存档条件。

## 连线的含义

点击资源块或流程节点右侧的出口，再点击目标块。玩家选择节点的每个按钮有独立出口；条件分支有满足、不满足两个出口。

| 连线 | 用途 |
| --- | --- |
| 前一关的具体选项 → 后一关 NPC 节点 | 前置条件。该节点等待这条故事历史中的实际选择，不会直接跳转执行到下一张地图。 |
| 重要状态 / 剧情道具 / 人物 / 任务 / 重要节点标签 → 流程节点 | 按值或数量检查前置条件。个人道具条件用于玩家交互规则。 |
| 流程节点 → 道具 / 状态 / 人物 / 任务 / 收藏 | 到达所选出口时执行效果。道具可发放或扣除，并选择作用于交互玩家还是全队每个人。 |
| 流程节点 → 战役事件 | 建线时选择作为前置条件，或在此出口执行事件。 |

多个前置条件需要全部满足。跨关前置连线沿同一战役由前章指向后章，禁止循环依赖和失效选项引用。本地对话返回仍用详细 NPC 画布原有的执行出口。

带前置连线的战役事件，在所属章节满足条件和波次后自动执行一次。包含个人道具发放或扣除的事件应由玩家交互的效果线显式触发，以确定操作谁的剧情仓库。

同一条效果线在同一章节历史中只结算一次，避免返回对话重复领取。重新回玩旧章会从当时的章节起点建立独立分支，已有存档和账号收藏保留。

右侧「管理全部跨关连线」可以编辑、断开连线；删除节点后遗留的引用也可在这里清理。旧版 NPC「触发战役事件」动作和战役状态条件继续兼容。

## 标签、检查点和恢复

选择节点后可添加重要节点标签、安全检查点标签，并选择具体出口。重要节点写入当前故事历史，也可从资源库作为后续条件引用。

战斗中到达安全检查点标签时，先记下保存请求，在下次开局、安全休整或通关阶段落盘。保存包含重要状态、剧情仓库、人物状态、NPC 已完成规则和正在执行的节点位置。继续时恢复流程位置，避免重新执行检查点之前的物品发放；对话窗口会重新创建。

## 保存和操作

- 「保存工作区」或 Ctrl+S：一起保存战役定义、画布和各地图 NPC 配置。详细 NPC 画布中的保存也保存整个工作区。
- 配置版本冲突、失效节点、未实际绑定的人物、越界位置等会在保存时指出，工作副本保留。
- 一次工作区保存有持久事务日志。进程在多文件写入之间中断时，下次读取会完成整份已验证的保存；恢复完成前不会带着混合版本开局。
- 滚轮缩放，中键或右键拖动画布，拖动地图分区标题移动整个分区；右侧「定位本关卡」放大当前地图。
- Ctrl+Z / Ctrl+Y 撤销和重做。小窗口通过「属性」展开右侧操作面板，面板内可滚动。

默认 H 打开个人主页，遵循 MC 中已有的自定义按键设置，与是否加入对局无关。客户端和服务端均需安装 0.2.35b（NPC 对话通道协议 12）。

开局失败时会显示具体事件、NPC 或配置项和原始原因，日志保留异常堆栈。场景快照引用的模组方块、实体必须仍已加载；禁用对应模组后，需要恢复模组或重新读取相应场景快照，不会静默丢弃它们。
