0.2.20b 在僵尸部署工具中新增“波次与地图剧情”。客户端和服务端都需更新。手持部署工具，Ctrl+右键进入，选定关卡并先保存关卡部署修改，再点击此按钮。

界面有四页，已新增条目按卡片依次列出，点标题展开编辑；鼠标滚轮上下滚动。底部“保存配置”提交全部四页，“重新读取”取回服务器版本。未保存离开会提示，保存时会检查其他部署者是否修改过配置；对局进行时只允许读取。收起查看地图后可移动和瞄准，再次 Ctrl+右键部署工具会回到本工作副本。

1. **波次怪物**：首次读取已有 `waves/wave_*.json` 的配置。新增或展开波次，设置编号、首领入场音效、生命／伤害／速度倍率、同时存活上限与最快／最慢刷怪间隔。每种怪物可选择种类、数量、独立倍率和击杀／助攻积分。间隔单位是游戏刻，20 刻约 1 秒；留空的可选参数沿用关卡默认值，填写 0 的无效倍率或间隔会被拒绝。空怪物列表可作为空波次。保存使用与旧文件相同的怪物、数量和参数验证。
2. **出场人物**：先新增人物，再编辑显示名字、名字颜色、正文颜色、粗体及斜体。颜色支持原版英文名或 `#RRGGBB`，也提供预设列表。人物编号保持稳定，修改显示名字不会破坏引用；删除仍被台词使用的人物时，先改掉相应台词的人物引用再保存。
3. **波前对话**：为指定波次新增台词序列，每句选择已定义人物或无名旁白，填写正文与“本句停留（秒）”；可新增、删除、上移及下移台词，预览只显示在编辑界面，不广播给玩家。先等待“开播前等待”，再按顺序发到本房间聊天栏；每句停留结束后显示下一句，最后一句也会完整等待。只有波前对话与原有波次间歇都结束，才进入刷怪阶段，等待期间不消耗战斗阶段计时。旧 `wave_text` 文件中的首句延迟与后续句间隔会在首次导入时保留，末句默认额外停留 1 秒。
4. **地图事件**：每个事件有稳定编号，可设置多个方块／区域变化、天气与时间。两端坐标相同即单个方块；可直接编辑坐标，或收起界面移动后使用准星方块取起点／终点。用方块图标列表选择部署方块，也可填写方块状态；“清空区域为空气”用于拆除墙壁等结构。单区域最多 4096 格，一个事件最多 16 区域、合计 8192 格，位置必须在本关卡范围内。

事件有两种调用方式：

- 开启“自动检查触发”：在对局中检查最低波次以及指定 NPC 规则是否已完成，两项需同时满足；波次 0 表示没有波次限制，NPC 规则选“不限”则不检查规则完成。例如“达到第 5 波且 guide.quest 已完成”之后移除墙壁并变成雷雨。
- 关闭“自动检查触发”：由 NPC 画布中的“触发地图事件”动作调用。先保存事件，再重新读取 NPC 配置，从动作下拉菜单选择事件编号；可把玩家回答的出口连到此动作，也可以插在任意剧情步骤之后。此调用由剧情中的判断与连线控制，不再使用事件的自动检查门槛。

每个事件每局最多执行一次，重复触发不会重复修改地图。再次开局会清空事件完成记录。事件对方块的要求沿用 NPC 方块动作：支持静态建筑方块、空气和门类，不支持流体、重力方块、红石设备、容器等有连锁变化或实体数据的方块；不能覆盖已部署的屏障、窗口或交互设备。多格门应分别为上下格设置正确状态，已有屏障仍可用 NPC 的打开屏障动作。

天气可选晴朗、下雨、雷雨；时间为 0–23999，也可一键设为白天／夜晚，设置后房间显示时间固定为该值直到对局结束。**天气与时间只改变本房间玩家的画面，不修改整个维度的天气、太阳时钟或游戏规则。** 因而不会改变其他关卡，也不会改变服务器依赖真实昼夜／天气的生物或作物逻辑。玩家离开房间或对局结束后恢复所在维度的显示。方块变化则实际发生在关卡地图中，在正常结束、管理员结束、开局回滚或服务器关闭时恢复；方块原状先记录到持久恢复日志，再应用变化，服务器重启时恢复未清理的记录。

四页内容一起保存在关卡规则目录 `scenario.json`：

`<世界>/serverconfig/codpattern/maps/zombies/m-<关卡名编码>/rules/scenario.json`

首次保存前仍使用原有 `waves` 与 `wave_text` 文件。首次进入界面会导入这些文件，保存后 `scenario.json` 中的 `waves` 是运行时使用的波次配置，同文件中的 `dialogues` 是已部署的波前对话；原文件保留，之后手改旧文件不会覆盖已保存的界面配置。保存后以界面的完整台词列表为准：删除波前对话条目或清空其台词会取消该波播放，不会重新播放已导入的旧文本。只在从未通过本界面保存的旧关卡中继续读取旧 `wave_text` 文件。NPC 配置仍保存在独立的 `npcs.json`，无需移动。

自动化验证包含：文本超过间歇时仍阻止进入刷怪阶段、最后一句阅读时间、波次及 NPC 组合触发、NPC 动作调用事件、区域恢复、越界／超大区域拒绝、旧波次导入、保存后的开局读取、并发保存冲突以及大小窗口界面操作。运行方式沿用 NPC 自动测试：

```powershell
.\gradlew.bat build runZombiesDeployCompatSuite runGameTestServer runClient -PnpcGameTests -PnpcClientPreview -PgameTestRunDirectory=build/gametest/scenario
```
