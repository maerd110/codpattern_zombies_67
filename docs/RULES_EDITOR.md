# 屏障与武器池部署（0.2.31b）

手持部署工具、选择关卡并保存物件草稿后，点击“武器池与品阶”。每个页签编辑一个原有 JSON 文件，点击“保存当前配置”写入；切换页签、重新读取或离开前，未保存修改会要求确认放弃。对局中允许查看，但不能修改；新参数在下次开局读取。客户端和服务端都需更新。

## 屏障规则

先沿用原来的方法，在地图中框选屏障并保存。然后在物件部署中选中该屏障，在右侧设置中点击“编辑屏障参数”，直接进入它绑定的分组／规则编号。

这里可设置点数价格、可选钥匙，再进入“编辑开门后刷怪／玩家出生组变化”设置联动效果。钥匙可以填写物品 ID／完整 NBT，也可从背包图标中读取，保留名字和自定义数据；匹配与消耗语义沿用原规则。

该入口只编辑已部署的屏障，不再提供独立的“新增屏障分组／新增购买入口”。分组和规则编号继续在原物件设置中修改，需为正整数，保存几何后再编辑对应参数。共用分组的屏障共享开门联动效果；同分组、同规则编号的屏障还共享价格和钥匙条件。初次进入未配置的绑定时，会建立待保存的参数草稿。

“屏障规则”页签只列出已经部署的屏障。已有但未绑定的旧配置保留，不会静默删除。新分组与入口的保存需能对应已部署屏障。出生组列表以逗号分隔非负整数，0 有效；同一类列表不能同时启用和停用同一组。引用的出生组需要已部署，完整地图校验会报告缺失引用。

## 墙枪和神秘箱

分别对应 `weapon_wall.json` 与 `mystery_box.json`。进入页签后先选择品阶卡片，再编辑该品阶参数：初始权重、每次刷新的权重增量、权重下限、权重上限。墙枪还可编辑该品阶价格；神秘箱的抽奖价格和两者的刷新间隔位于各自首页。

“编辑此品阶枪械”中显示已选枪械卡片，进入后修改枪械权重、替换或删除。点击“从所有枪包添加枪械”打开枪械图标选择器。可先在“枪包”中选择分类，显示枪包名称、编号和枪械数量，再搜索枪名或 ID；“全部枪包”恢复完整列表。分类使用 TaCZ 的枪包命名空间与本地枪包信息。中文名称由客户端枪包解析，图标边框与当前品阶颜色一致。列表来自服务端 TaCZ 实际加载的枪械索引，不要求枪械先放入背包。客户端也需安装对应枪包，才能正常显示其模型和翻译。

默认普通为绿色，稀有为蓝色，史诗为紫色，传奇为橙色。所有品阶（包括自定义品阶）均可在“品阶与强化”中选择颜色。

### 概率含义

保存的是原 JSON 的相对权重，不是直接百分比。界面显示品阶初始占比，以及枪械在该品阶内的占比，作为配置参考。

一次刷新先选择品阶，再按品阶内枪械权重选枪；品阶权重随刷新次数按增量变化，并限制在上下限内。空枪池不参与初始占比计算，枪械权重 0 表示不出现。修改任意权重会影响同组其他条目的占比，多个枪械可以出现在不同品阶，但同一品阶内不能重复。

## 品阶与强化

对应 `weapon_rules.json`。品阶伤害倍率统一在这里编辑，不在两个武器池中分别设置。品阶详情分别编辑：

- **显示名称（支持中文）**：显示给玩家看的名字，例如“终极”。保存为 `displayName`，最多 64 个字符，留空使用默认名称。内置品阶也可以改名。
- **内部编号**：保存为 `id`，用于武器池与装备标签的稳定绑定，只允许 1 至 64 个小写英文字母、数字、下划线和短横线。新增品阶会自动生成，例如 `custom_2`；通常只需修改显示名称，保留编号即可。格式无效与编号重复会分别提示具体原因。

例如 `{"id":"custom_2","displayName":"终极","damageMultiplier":3,"color":"#EF4444"}`。武器池仍引用 `custom_2`，页面、墙枪、NPC 和枪械标记显示“终极”；修改名称不改变伤害、概率及已有绑定。旧配置没有 `displayName` 时保留内置中文名，自定义品阶退回显示编号。武器池添加品阶时读取已配置的编号和名称。

进入品阶卡片，点击“品阶颜色”可选预设色块，或输入 `#RRGGBB` 精确颜色。保存为该品阶的 `color` 字段，例如 `"color": "#E71DA4"`。旧 JSON 没有此字段时，内置品阶保持原颜色，自定义品阶默认青绿色。

开局后由服务器同步当前房间的品阶名称与颜色，抽奖领取光柱、墙枪名称与提示、右下角枪械卡片、NPC 枪械和队伍标记统一读取；退出房间或换房间会替换配置，避免同名品阶串色。编辑页使用自己的草稿，不改变进行中房间的颜色。

“编辑强化等级与价格”支持最大强化等级及各级价格、伤害倍率。沿用原 JSON 的 `upgrades.maxUpgradeLevel` 和 `levels` 格式；新增等级参数后，需要同时提高最大等级才会生效。

## 保存保护

仅管理员且手持部署工具可以读取和保存，保存需关卡处于等待阶段。文件有独立版本校验，其他部署者或外部编辑器修改过后，旧页面不会覆盖新文件。无效的数字、重复枪械、未加载的枪械、无效钥匙和冲突的出生组操作会阻止保存，原文件保持不变。

每次通过临时文件原子替换单个配置，编辑屏障不会改写武器池，编辑武器池也不会改写其他配置。字段沿用已有格式，原 JSON 中额外的字段保留，不生成第二套配置来源。
