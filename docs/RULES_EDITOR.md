# 屏障与武器池部署（0.2.29b）

手持部署工具、选择关卡并保存物件草稿后，点击“屏障与武器池”。每个页签编辑一个原有 JSON 文件，点击“保存当前配置”写入；切换页签、重新读取或离开前，未保存修改会要求确认放弃。对局中允许查看，但不能修改；新参数在下次开局读取。客户端和服务端都需更新。

## 屏障规则

“屏障分组”卡片对应 `barrier_groups.json` 的 `groups`。每组设置开门后刷怪组和玩家出生组的启用、停用列表，使用逗号分隔非负整数；0 是有效的出生组编号，同一类列表不能同时启用和停用同一组。

每组内的“购买入口”卡片对应 `entries`，单独设置点数价格与可选的钥匙物品。钥匙可以直接填写物品 ID／完整物品 NBT，也可从背包图标中读取，保留名字和自定义数据。钥匙的匹配与消耗语义沿用原有运行规则。

分组和购买入口均可输入正整数编号后点击“应用编号”。创建、删除或更换编号后，需要在物件部署中相应设置屏障的 `group` 和 `entryId`；本页不会擅自改写屏障几何、入口绑定或批量修改其他屏障。返回部署工具时刷新可用规则选项。启停列表中引用的出生组需要已在地图中部署，完整地图校验会报告缺失引用。

## 墙枪和神秘箱

分别对应 `weapon_wall.json` 与 `mystery_box.json`。进入页签后先选择品阶卡片，再编辑该品阶参数：初始权重、每次刷新的权重增量、权重下限、权重上限。墙枪还可编辑该品阶价格；神秘箱的抽奖价格和两者的刷新间隔位于各自首页。

“编辑此品阶枪械”中显示已选枪械卡片，进入后修改枪械权重、替换或删除。点击“从所有枪包添加枪械”打开可搜索的枪械图标选择器，中文名称由客户端枪包解析，图标边框与当前品阶颜色一致。列表来自服务端 TaCZ 实际加载的枪械索引，不要求枪械先放入背包。客户端也需安装对应枪包，才能正常显示其模型和翻译。

普通为绿色，稀有为蓝色，史诗为紫色，传说为橙色。未识别的自定义品阶使用备用颜色。

### 概率含义

保存的是原 JSON 的相对权重，不是直接百分比。界面显示品阶初始占比，以及枪械在该品阶内的占比，作为配置参考。

一次刷新先选择品阶，再按品阶内枪械权重选枪；品阶权重随刷新次数按增量变化，并限制在上下限内。空枪池不参与初始占比计算，枪械权重 0 表示不出现。修改任意权重会影响同组其他条目的占比，多个枪械可以出现在不同品阶，但同一品阶内不能重复。

## 品阶与强化

对应 `weapon_rules.json`。品阶伤害倍率统一在这里编辑，不在两个武器池中分别设置。可维护自定义品阶编号；武器池添加品阶时读取已配置的编号。

“编辑强化等级与价格”支持最大强化等级及各级价格、伤害倍率。沿用原 JSON 的 `upgrades.maxUpgradeLevel` 和 `levels` 格式；新增等级参数后，需要同时提高最大等级才会生效。

## 保存保护

仅管理员且手持部署工具可以读取和保存，保存需关卡处于等待阶段。文件有独立版本校验，其他部署者或外部编辑器修改过后，旧页面不会覆盖新文件。无效的数字、重复枪械、未加载的枪械、无效钥匙和冲突的出生组操作会阻止保存，原文件保持不变。

每次通过临时文件原子替换单个配置，编辑屏障不会改写武器池，编辑武器池也不会改写其他配置。字段沿用已有格式，原 JSON 中额外的字段保留，不生成第二套配置来源。
