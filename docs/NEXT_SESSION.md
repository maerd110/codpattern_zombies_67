# 当前交付：0.2.35b 战役逻辑画布

## 本次完成

- 部署工具「NPC 剧情」和「战役逻辑画布」统一入口，取代空泛的战役列表表单。已部署地图自动分区，背景随节点适应范围；NPC 流程节点、剧情资源、标签、条件和效果连线共处一个工作区。
- NPC 详细编辑器以共享工作副本嵌入，保存提交整个战役工作区，不独立覆盖其中一张地图。保留原有动作、对话、分段选择、投票和本地执行流程。
- CampaignCanvas：稳定章节/人物/规则/节点/具体出口身份；REQUIRE 是前置门禁，EFFECT 是剧情资源效果。节点选择事实、标签、效果一次性领取记录进入故事历史，旧章回玩不会带入未来事实。
- 跨关前置只允许同战役前章到后章；校验失效选项/节点、人物绑定、循环依赖、个人仓库条件接入自动规则等。账号收藏不作为故事存档门禁。
- 人物模板保存身份、外观、皮肤、称呼、默认台词和来源，剥离原坐标。本关规则独立；引用只产生未放置卡片，实际选定位置后才写入地图 NPC。源地图已有 NPC 自动绑定身份，不会重复生成。
- 剧情道具、重要状态、任务、事件、账号收藏均可用中文名称编辑、按名称引用。道具可读取副手展示外观；任务可激活/完成/失败；事件可由条件或效果线触发。
- 节点标签在战斗时先排队，到安全阶段保存。NPC 检查点补存正在执行的规则/节点/台词段/剩余等待/动作已完成状态，恢复不会重跑之前的物品奖励。
- CampaignAuthoringTransaction：持久多文件提交日志，包含 campaigns.json 与变更的各地图 npcs.json；启动、配置读取时先完成中断事务，不能带混合部署版本开局。
- 开局失败保留原始异常信息、事件/NPC/配置上下文与堆栈，聊天不再只有 startup.preflight_failed。定位过一次因禁用 helicopter 模组而无法读取快照直升机实体的情况；按用户选择已重新启用原模组，需要重启游戏加载。
- 个人主页保留自定义按键，增加同键冲突兼容；无对局状态限制。用户当前客户端实际绑定为 O，默认新配置为 H，未覆盖用户设置。
- 通道协议 12，客户端与服务器均需 0.2.35b。旧 campaigns.json 与旧账号/存档数据继续读取。

## 保留的边界

- 同一物理地图多队世界副本、动态分支章节出口、完整任务日志、称号/实体纪念枪展厅/全服邮件仍未加入；没有宣称完成这些后续功能。
- 同一地图复用为多个章节时物理 NPC 程序共用；用章节身份、故事状态和门禁区分剧情。
- 每个目标的多个前置条件按 AND 判断；可在 NPC 本地条件分支中组合更复杂判断。
- 一个工作区沿用现有 2 MiB 通道保护。超限在保存前拒绝并保留工作副本。
- 人物模板复用身份与外观，不直接搬运含旧地图坐标的完整规则程序。
